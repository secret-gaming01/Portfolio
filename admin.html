🔐 Connexion

Ce panneau modifie directement le fichier data/content.json de ton repo GitHub. Il te faut un token GitHub (une seule fois).

📋 Comment créer mon token (2 minutes)
  1. Va sur github.com → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Nom : portfolio-admin — Expiration : 90 jours
  3. Repository access : « Only select repositories » → choisis secret-gaming01/portfolio
  4. Permissions → Repository permissions → Contents → Read and write
  5. « Generate token », copie le code (github_pat_...) et colle-le ci-dessous.

⚠️ Le token reste uniquement dans TON navigateur. Ne le partage jamais.
